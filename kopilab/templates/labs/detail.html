PANDUAN OPSIONAL · BURP SUITE

Cara melihat request untuk lab ini

Bagian ini khusus untuk {{ lab['title'] }}. Burp membantu melihat permintaan yang dikirim browser ke KopiLab dan jawaban yang dikirim kembali. Kamu tidak perlu mengubah request untuk mulai belajar. Jika belum memasang atau membuka Burp, lanjutkan praktikum dengan browser biasa.

Request yang menjadi fokus di lab ini{{ lab['endpoint'] }}
  1. Jalankan KopiLab seperti biasa dan biarkan terminal server tetap terbuka. Pastikan http://127.0.0.1:5000 bisa dibuka. 127.0.0.1 berarti komputer yang sedang kamu gunakan.
  2. Buka browser dari Burp. Di Burp Suite pilih Proxy, lalu Open browser. Di browser baru itu, buka http://127.0.0.1:5000 dan masuk kembali ke halaman lab ini.
  3. Matikan Intercept untuk mulai. Di Burp, buka Proxy > Intercept dan pastikan tertulis Intercept is off. Dengan begitu browser tidak berhenti menunggu request diteruskan.
  4. Lakukan langkah praktikum lab ini dari bagian Langkah praktikum menggunakan browser Burp. Jika langkah meminta membuka halaman atau mengirim form, lakukan aksi itu di KopiLab yang sedang berjalan di komputermu.
  5. Cari request di HTTP history. Kembali ke Burp dan buka Proxy > HTTP history. Pilih entri ke 127.0.0.1 pada port 5000 yang path-nya cocok dengan target di atas. Endpoint yang menuliskan <id> atau ... adalah pola alamat; nilai sebenarnya bergantung pada data atau isian langkah praktikum.
  6. Amati, jangan langsung ubah. Lihat method seperti GET atau POST, path, parameter yang memang kamu kirim, dan response KopiLab. Bandingkan dengan hasil yang terlihat di browser. Jangan salin atau bagikan nilai Cookie, karena itu dapat berisi pengenal sesi.
  7. Bandingkan mode. Jika ingin melihat perbedaan, ulangi aksi praktikum yang sama setelah mengganti mode melalui tombol mode di KopiLab. Perhatikan apakah response berubah. Untuk langkah pertama, cukup amati request dan hasilnya.
Jika browser menunggu

Buka Proxy > Intercept. Jika ada request yang tertahan, klik Forward untuk meneruskannya. Setelah itu ubah status menjadi Intercept is off. Untuk panduan Burp dari awal, termasuk pemecahan masalah, buka Deep Dive: panduan Burp Suite.

Gunakan Burp hanya pada KopiLab lokal yang kamu jalankan sendiri. Jangan mengubah tujuan request ke situs, komputer, atau server lain.
